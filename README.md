# hxwl-01 助听设备结算与补贴核销台

在原「听力验配记录」工作台基础上扩展的助听设备结算登记、补贴抵扣与冲突核销页面。

## 技术栈

React + Vite + TypeScript + CSS（不增加任何依赖，持久化使用浏览器自带 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 业务规则

1. 每笔登记设备序列号、助听设备项目、应收金额、实收金额与补贴金额。
2. 补贴按医保凭据或公益凭据抵扣：补贴大于 0 时凭据类型与编号必须齐全。
3. 一个设备序列号全台账只能绑定一位客户，绑定他人整笔挂起。
4. 补贴金额不得超过实收金额，超额整笔挂起。
5. 必填缺失或金额格式无效时整笔挂起，原始输入原样保留，可「取回修改」。
6. 校验通过的登记进入「待确认」；确认后应收/实收/补贴金额冻结。
7. 冻结记录只允许补录：必须填写修订原因，新建升号版本，旧值与凭据保留在历史版本中，新版本须重新校验、重新确认。
8. 冲突统一列出：客户、项目、原值、限制（含序列号占用、凭据缺失、补贴超额、字段缺失/格式）。
9. 台账信封整体落盘，刷新后记录、凭据、金额与版本保持一致。

## 分层结构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 数据 | `src/types.ts`、`src/data.ts` | 领域模型与演示台账（冻结修订、挂起冲突、待确认样例） |
| 判定 | `src/rules.ts` | 纯函数：金额解析、序列号绑定、补贴/凭据校验、冻结、修订、汇总 |
| 存储 | `src/storage.ts` | localStorage 信封读写、结构校验、损坏回落演示数据 |
| 界面 | `src/App.tsx`、`src/components.tsx`、`src/styles.css` | 登记表单、台账记录卡、冲突明细表、筛选与指标 |
